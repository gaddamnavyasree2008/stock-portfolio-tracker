# Stock Portfolio Tracker Using Python

## 📌 Project Description
The Stock Portfolio Tracker is a simple Python-based application that helps users track their stock investments. Users can enter stock symbols and quantities to calculate the total investment value based on predefined stock prices.

## ✨ Features
- Displays available stock symbols.
- Allows users to enter stock names.
- Accepts the quantity of shares.
- Calculates the total investment value.
- Displays the portfolio summary.
- Simple and beginner-friendly interface.

## 🛠️ Technologies Used
- Python 3
- Python IDLE

## ▶️ How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the `stock_portfolio_tracker.py` file in Python IDLE.
4. Press F5 to run the program.
5. Enter the stock symbol and quantity when prompted.
6. View the total investment value.

## 💻 Stock Prices Used
The project uses predefined sample stock prices:

- AAPL – $180
- TSLA – $250
- GOOGL – $140
- MSFT – $410
- AMZN – $175
